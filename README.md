# MecaniSoft

Copia inicial del proyecto MecaniSoft para revisión, visualización y análisis.

> El código original fue importado desde `MecaniSoft-main.zip`. Los archivos de dependencias generadas/voluminosas se mantienen fuera de esta primera carga para facilitar la revisión del código fuente.

## Estructura
- `controlador/` — controladores PHP
- `modelo/` — modelos y acceso a datos
- `vista/` — interfaz y páginas
- `js/` — lógica JavaScript
- `db/` — esquema/base de datos
- `MPDF/` — generación de reportes PDF

## Estado
Carga inicial para auditoría funcional y técnica. No se han modificado las credenciales ni la lógica del proyecto original.
